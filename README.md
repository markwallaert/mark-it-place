# mark-it-place

Curated Claude Code plugins.

## Install

In a Claude Code session:

```
/plugin marketplace add markwallaert/mark-it-place
/plugin install <plugin>@mark-it-place
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [standup](plugins/standup) | Daily standup synthesizer — turns Claude Code transcripts into dated markdown entries, cross-project by default or per-project with `--project` |

Each plugin carries its own README and license.
